About Catalogue Plots

This website is a community-driven project collecting all currently known exoplanets with ages of < 1 Gyr, aiming to be the most complete record of the young exoplanet population and allow the community to keep track of the rapidly evolving young exoplanet field.

Using the catalogue

We provide an interactive catalogue of the planets which allows the user to sort by a variety of parameters from age, mass and radius to discovery method and year, and also easily select a sub-set of planets to download and analyse further. We also provide simple 2D plotting tools to quickly inspect the planetary population, which is directly tied to the catalogue page to allow users to easily plot sub-samples of the catalogue.

Suggestions and missing planets

We create this public repository for the benefit of the community, so if you have any additional features that you would like to see on the website then please just reach out and let us know! Please note that while every effort has been made by the authors to include and continually update the catalogue of all known young exoplanets, we’re still human, so if you spot a missing young exoplanet then just send us an email.
